# Reliability and validity

A 12-report repeat-scoring sample (15% of the 80-report corpus) is available in `data/input/reliability_recode.csv`. Exact percentage agreement and quadratic-weighted Cohen's kappa are calculated for each item and pooled across all 144 repeated decisions.

**Important provenance rule:** the repository uses the neutral term **repeat scoring**. It should only be described as *intra-coder* or *inter-coder* reliability when the identity/independence of the second scorer is documented.

The pooled weighted kappa is **0.631**. Item-level agreement varies, so the aggregate statistic must not be presented as uniform reliability across all CFCQI dimensions.

Construct validity is supported by the climate-financial focus of the 12 items, the distinction between qualitative and quantified/specific connections, full-report review before assigning zero, a frozen codebook, evidence traceability and automated integrity checks. The CFCQI is a disclosure-depth measure, not a climate-performance or regulatory-compliance score.
