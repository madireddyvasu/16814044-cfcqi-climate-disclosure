# Project overview

**Student:** Vasu Deva Rao Madireddy (16814044)  
**Programme:** MSc Business Analytics, Coventry University  

This project measures the extent to which climate-sensitive FTSE 350 firms connect climate disclosure to financial effects, quantification, planning and financial statements. It introduces the **Climate Financial Connectivity and Quantification Index (CFCQI)**, a 12-item 0–2 scoring framework converted to a 0–100 index.

The analytical unit is the **firm-report-year**. Forty firms contribute two reporting cycles each, producing 80 observations and 960 item-level scoring decisions.

The project combines verified annual-report evidence, structured quantitative content analysis, descriptive Business Analytics, pooled OLS with firm-clustered standard errors, reliability assessment, diagnostics, paired-cycle testing and robustness analysis.
